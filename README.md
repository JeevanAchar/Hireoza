# Mono Repo with Lerna, NPM, Node, Fastify, React and Vite

This is a mono repo that uses Lerna as its package manager, with NPM as the package manager.
The mono repo contains three packages:

* `api`: a Node.js API using Fastify
* `client`: a React client using Vite and TypeScript

The `api` package contains a Node.js API that uses Fastify as its framework.
The `client` package contains a React client that uses Vite and TypeScript.
